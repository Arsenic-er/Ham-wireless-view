# 真实参数敏感性矩阵验证

- 日期：2026-07-28
- 状态：服务器真实成都 DEM/WBM 参数矩阵通过
- 数据源：`.runtime/validation-platform/data/`；计算输入为受锁保护的一致临时快照
- 基线代码：`9f3247f5d13a9d545607aaec6bd36978a25532c3` 加本切片工作树
- 部署影响：无；未停止、替换或重启受管验证平台

## 1. 目的

本门禁直接验证产品验收标准中的参数响应，而不是只检查表单或把理论值写进报告：

- 相同输入产生相同原始 dBm 栅格、报告 PNG 和界面使用的 EPSG:3857 地图覆盖 PNG；
- 功率增加 10 倍时，每个有效像素约增加 10 dB；
- 发射和接收天线增益分别进入链路预算；
- 145/435 MHz、两端天线 AGL 和水平/垂直极化产生真实的空间变化。

这项测试证明当前 ITM 实现会响应用户输入；它不是外场测量校准，也不证明预测与真实通联完全一致。

## 2. 方法

`app-service` 的 ignored 真实缓存测试通过私有 `request_to_config` 路径归一化与桌面相同的 `CalculationRequest`，一次加载成都周边 25 个 DEM 和 25 个 WBM，然后对每个场景运行完整的 401×401、200 km、1 km 输出。

比较口径：

- 圆外 NaN 掩膜在所有场景中必须完全一致；
- 125,628 个圆内有效像素逐像素比较；
- 功率和增益的统一偏移误差上限为 `0.00005 dB`，用于容纳最终 `f32` 量化；
- 频率、高度和极化至少 1% 像素变化超过 `0.01 dB`，且最大与最小差值跨度超过 `0.1 dB`，排除只发生统一常数偏移；
- 相同输入的所有 `f32::to_bits`、报告 PNG 和 EPSG:3857 地图覆盖 PNG SHA-256 必须一致；
- 每个参数对照的报告 PNG 与地图覆盖 PNG 都必须不同于基线。

脚本先逐路径分量拒绝符号链接，再用真实 `.cache.lock` 取得短期独占权，在锁内复制包含 SQLite、DEM/WBM 和 lock 文件的一致快照。矩阵只打开快照；真实缓存锁保持到测试结束，前后比较全部常规文件的 SHA-256 清单和目录字节数。这样测试触发的 reconcile/last-used 更新只发生在快照，不会写真实缓存。脚本不启动、停止或重建 validation 服务。

## 3. 结果

基线为成都 `(30.5, 103.5)`、145 MHz、25 W、发射 `6 dBi / 20 m AGL`、接收 `-3 dBi / 1.5 m AGL`、垂直极化。

| 对照 | >0.01 dB 变化像素 | 改善 | 变弱 | 平均差值 | 最小～最大差值 |
|---|---:|---:|---:|---:|---:|
| 250 W − 25 W | 125,628 | 125,628 | 0 | +10.000000 dB | +9.999992～+10.000008 |
| TX 12 − 6 dBi | 125,628 | 125,628 | 0 | +6.000000 dB | +5.999992～+6.000008 |
| RX 3 − -3 dBi | 125,628 | 125,628 | 0 | +6.000000 dB | +5.999992～+6.000008 |
| 435 − 145 MHz | 125,628 | 0 | 125,628 | -18.068198 dB | -45.764847～-0.557541 |
| TX 80 − 20 m AGL | 124,615 | 38,769 | 85,846 | -0.741523 dB | -21.249191～+34.645020 |
| RX 10 − 1.5 m AGL | 125,074 | 53,808 | 71,266 | +0.945559 dB | -18.610565～+66.413223 |
| 水平 − 垂直极化 | 102,984 | 1,250 | 101,734 | -0.700784 dB | -5.568375～+1.492321 |

天线升高不会被强行断言为“全图平均一定增强”。真实地形、干涉和 ITM 模式转换可使部分路径变弱；验收标准要求的是遮挡区中存在改善，本次 TX 高度对照有 38,769 个像素改善，RX 高度对照有 53,808 个像素改善。

确定性证据：

- 原始 dBm 栅格 SHA-256：`3415f575c8f7c8a51f3ca8fa4f4387be3055382aea527ec064206ca8ffb0429a`；
- 重复运行栅格 SHA-256：相同；
- 报告 PNG SHA-256：`78e5adb8debe7aa213c55d38765a608d1bf5ac9fb1890d9e57c582939cf7b125`；
- 地图覆盖 PNG SHA-256：`58e8dc314c607a38270f3d6dd923574ced2e2587e128c10b12d3bd7cea39786b`；
- 重复运行两种 PNG SHA-256：均相同；七个参数场景的两种 PNG 均与基线不同，完整哈希写入结构化测试输出。

缓存不变性：

- 运行前后缓存目录均为 `133,079,734` 字节；
- DEM/WBM payload 数量均为 `50`；
- 包含 SQLite 与 lock 文件的完整源缓存清单 SHA-256 为 `a850ee81b363e91c88a638f836f7199882b27c97f358da8be975fa6cc1b919bf`；
- 没有遗留 partial 或测试运行目录。

最终精确测试选择器运行耗时 `25.92 s`；快照、矩阵和清理端到端为 `28.7 s`。

## 4. 复现

```bash
cd /home/ubuntu/hamheatmap
scripts/parameter-sensitivity-smoke.sh
```

普通工作区测试不会自动运行真实矩阵；它保持 ignored，避免在没有成都真实资产的开发环境中产生伪失败。脚本固定从项目内 validation 缓存复制快照，拒绝参数、任一路径分量中的符号链接和少于成都所需 50 个 payload 的不完整数据，但允许缓存中正常存在其他地区资产。

## 5. 边界

本门禁不替代：

- Windows 10/11 WebView2 表单到 Rust 的实机检查；
- 中国大陆合规底图、审图号、离线与导出授权；
- 建筑、植被、干扰、天气和异常传播建模；
- 真实电台、天线和站址的外场测量校准。
