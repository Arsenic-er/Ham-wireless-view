项目开发对话包含服务器地址、本地路径、临时认证流程、测试坐标、运行状态和 AI 协作细节。公开原始逐字记录会泄露与软件功能无关的信息，因此本仓库只保存经过归纳和脱敏的需求、决策、里程碑、验证结果与未完成事项。本文是当前对话历史的项目级摘要，不是逐字聊天导出。

## 2. 项目起点与目标

HamHeatmap 起源于一个面向业余无线电爱好者的 Windows 桌面工具设想：在地图上选择发射点，结合真实地形、传播模型、设备参数和陆水差异，计算固定范围的接收功率热力图。主要使用场景包括手台预测、中继台选址、基站覆盖分析、应急规划与野外通信。

用户确认的核心边界如下：

- 支持 144 MHz 和 430 MHz，具体频率可输入到小数点后两位。
- 发射端是覆盖计算中的唯一站点；输出单位为 dBm。
- 计算半径固定为 200 km，输出网格固定为 1 km，即 401 × 401 栅格。
- 参数包括发射功率、收发天线增益、收发天线高度、收发点地面海拔和水平/垂直极化。
- 不增加馈线损耗，不配置天线方向图，增益统一按 dBi。
- 计算考虑真实地形遮挡、绕射以及统一水体/陆地电气参数。
- 首版不考虑建筑、植被、城市杂波、外部干扰、实时天气或异常传播。
- 地形只参与隐藏计算，不在地图上绘制山体或高程图层。
- 热力图不提供单像素检查；弱于显示阈值的像素透明。
- 强到弱色标为红、橙、黄、绿、青、蓝。
- 支持浅色/深色界面以及英语、简体中文、繁体中文和日语。
- Windows 10/11 x64 是目标平台；视觉底图最终确定为纯在线，不打包离线地图。
- 所有持久 DEM、WBM、临时文件、索引和计算缓存合计使用十进制 2.5 GB 硬上限。

## 3. 已实现的覆盖分析

当前实现使用 NTIA ITM / Longley–Rice 点对点传播计算。DEM 和水体掩膜来自 Copernicus DEM GLO-90 2021_1 / AWS COG。地形剖面、遮挡与绕射进入模型，水体分类被统一折叠为 land/water 两类。

覆盖结果具备以下交互：

- 地图单击设置发射点并计算固定圆形覆盖。
- 同一会话最多保留 8 个不同站点的热力图；同一站点重新计算会替换原层。
- “清空”只清除覆盖分析状态，不依赖地图源重载。
- 全局 -140..-60 dBm、步长 1 dB 的显示阈值可实时隐藏更弱像素，不重新运行传播模型。
- PNG/PDF 为无底图的内部诊断导出，并带模型、数据版本和限制说明。
- 已缓存完整计算数据的区域可在无网络时计算；视觉底图离线时降级到 WGS84 坐标网格。

## 4. 已实现的链路通视分析

后续对话新增了独立的两点链路分析模式：

- 在地图上依次选择 TX 和 RX，链路距离限制为 1–200 km。
- TX/RX 可分别设置天线高度、增益和水平/垂直极化。
- 使用真实 DEM/WBM 构造沿途地形剖面，样本间距不大于 90 m。
- 使用 k = 4/3 的有效地球半径处理长距离地球曲率。
- 绘制直射路径、完整第一菲涅尔区 F1 与 60% F1 净空边界。
- 地形图使用响应式 SVG，横轴动态显示距离刻度。
- 结果代码固定为 `direct-los`、`obstructed-usable` 和 `predicted-unavailable`。
- 结果以非模态浮动窗展示；点击窗外降为 42% 透明度，地图仍可交互，点击面板恢复。

这些分类是规划预测，不是实际通联保证。

## 5. 地图、地名与卫星图的演进

项目底图经历了坐标占位网格、私有四省 PMTiles、天地图代理和纯在线底图几轮验证。最终产品路线是：

- 普通地图默认使用 CARTO Voyager 及其地名标注。
- 卫星视觉层使用 EOxCloudless Sentinel-2 在线影像，并叠加在线地名。
- 天地图 `tk` 仅作为可选用户配置，不再是默认地图可用性的前提。
- Windows WebView2 通过受控的 `http://basemap.localhost` 与 `http://tianditu.localhost` 回环映射读取在线瓦片。
- 地图失败提示持久保留，包含安全分类、可复制的脱敏诊断和明确重试状态；原始 URL、token 与上游错误正文不进入诊断。
- 在线瓦片不持久缓存，不进入 2.5 GB 计算数据配额，也不嵌入诊断导出。

历史四省 PMTiles 只保留工程证据，不再是产品目标，也不进入 EXE 或 GitHub Release。

## 6. 主要开发里程碑

1. 建立 ITM、GLO-90、固定 200 km / 1 km 网格的最小可行性验证。
2. 实现区域缓存、2.5 GB 配额、恢复/取消语义与真实数据验证。
3. 建立 Tauri/React 桌面切片、渐进式覆盖预览和 PNG/PDF 诊断导出。
4. 增加 Web Mercator 叠加、动态比例尺、在线普通地图、地名与卫星图。
5. 修复会话多热力图保留和清空行为，增加动态 dBm 阈值。
6. 发布 Windows Alpha 1 与 Alpha 2。
7. 增加四语 UI、来源署名、作者信息和自动一致性检查。
8. 增加两点链路通视/Fresnel 分析与浮动剖面面板。
9. 将 Windows 默认地图改为无需共享 token 的在线 CARTO/EOX 路线。
10. 修复 Windows WebView2 在线地图协议、持久错误诊断和重试判定，形成 Alpha 3 归档版本。

## 7. 当前技术结构

- 前端：React 19、TypeScript、Vite、MapLibre GL JS。
- 桌面壳：Tauri 2。
- 计算与数据层：Rust workspace、SQLite、rustls、GeoTIFF 读取。
- 传播模型：官方 NTIA ITM C++ v1.4 封装。
- 数据：Copernicus DEM GLO-90 2021_1 DEM/WBM。
- Windows 构建：Linux 服务器上的 xwin/MSVC 交叉构建，生成独立 EXE 与 NSIS 安装包。

源码、依赖恢复脚本、测试脚本、Windows 交叉构建脚本和工程文档均已进入公开 Git 仓库。
