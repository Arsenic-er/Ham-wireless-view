# HamHeatmap 产品需求文档

- 文档版本：0.1-draft
- 日期：2026-07-16
- 状态：需求基线已确认，Phase 2 桌面 MVP 开发中
- 目标平台：Windows 10/11 64 位
- 项目性质：开源、单人 + AI 协作开发

## 1. 产品摘要

HamHeatmap 是面向业余无线电新手的中国大陆 VHF/UHF 地形传播覆盖预测桌面软件。用户在地图上单击设置一个发射点，输入或选择常见电台参数，软件计算以该点为圆心、固定半径 200 km 的接收功率热力图。

软件的核心价值是让用户从热力图结果中直观看到地形高度、山体遮挡、绕射、频率、功率、天线高度、天线增益、接收端条件、极化方式以及陆地/水面电气参数对覆盖结果的影响。高程数据只供计算引擎使用，底图不显示山体阴影、等高线或高程着色。

本软件是规划与教学工具，不保证真实通联。首版不考虑建筑物、植被、城市杂波、外部干扰、实时天气、电离层传播、异常传播或水面镜面反射。

## 2. 目标用户与使用场景

主要用户是没有传播建模经验的业余无线电爱好者。界面应优先使用日常电台术语，并将 ITM 高级统计参数隐藏为工程默认值。

按优先级支持以下场景：

1. 手台覆盖预测。
2. 中继台选址初步分析。
3. 基地台覆盖分析。
4. 应急通信规划。
5. 野外通信规划。

## 3. MVP 范围

### 3.1 包含

- 144 MHz 与 430 MHz 两类频段。
- 选择频段后输入具体频率，单位 MHz，精确到小数点后两位。
- 144 MHz 输入范围暂定 144.00–148.00 MHz。
- 430 MHz 输入范围暂定 430.00–440.00 MHz。
- 单一发射点。
- 固定 200 km 圆形计算范围。
- 固定 1 km 输出像素。
- 接收功率结果，单位 dBm。
- Longley–Rice / ITM 地形传播模型。
- 地形剖面、遮挡、绕射、地球曲率与标准大气折射。
- 水平、垂直两种极化，默认垂直。
- 陆地与水面采用不同的模型电气参数。
- 基地台到手台、手台到基地台两个预设。
- 计算进度、取消、渐进显示和同输入缓存。
- PNG 与单页 PDF 导出。
- 清空当前热力图并保留发射点和参数。
- 地图、高程、水体和计算缓存管理。
- 已缓存区域离线使用。
- 浅色、深色两套 UI 主题，默认跟随 Windows 系统设置。

### 3.2 不包含

- HF、电离层、卫星、月面反射。
- 多发射点、多个热力图叠加或候选点对比。
- 两点链路分析和地形剖面交互页。
- 项目文件、历史记录或结果恢复。
- 天线方向图、方位角、下倾角或具体天线型号库。
- 馈线和接头损耗。
- 调制方式、带宽、接收灵敏度或能否解调判定。
- 建筑物、森林、植被、城市杂波。
- 实时天气、逆温、导波等异常传播。
- 遥测、云同步、账号或在线协作。
- 热力图像素悬停、点击或单点数值检查。

## 4. 用户主流程

1. 启动软件，显示中国大陆及 200 km 外围缓冲范围的基础地图。
2. 用户在地图上单击一个位于中国大陆的发射点。
3. 软件读取该点 DEM 海拔并检查周围 210 km 数据是否完整。
4. 若缺失数据且在线，软件显示预计下载大小，用户一次确认后自动下载；若离线，软件阻止计算并提示先缓存该区域。
5. 用户选择“基地台 → 手台”或“手台 → 基地台”预设。
6. 用户选择 144/430 频段、具体频率、水平/垂直极化，并修改功率、增益、天线高度；发射点地面海拔可保持 DEM 自动或切换为手动覆盖。
7. 用户点击“开始计算”。
8. 软件显示进度、允许取消，并逐步绘制已有热力图。
9. 完成后地图显示固定色标、发射点、200 km 边界和模型名称。
10. 用户可以导出 PNG/PDF，或点击“清空”开始新的分析。

### 4.1 主界面布局

- 中央约 70% 为地图，右侧约 30% 为参数面板。
- 右上提供缓存管理、导出、设置和主题切换入口。
- 右下提供开始计算、取消和清空。
- 地图左下显示发射点坐标，右下显示随地图缩放动态变化的公制比例尺；地图下方显示固定色标。
- 计算期间锁定参数输入，完成或取消后恢复。
- 选择发射点后，参数区显示十进制度坐标、DEM 海拔、Maidenhead 网格和数据缓存状态。
- 浅色和深色主题只改变 UI 与合规底图样式，不改变热力图色标。

## 5. 输入参数

### 5.1 用户可见参数

| 参数 | 单位与范围 | 默认/行为 |
|---|---|---|
| 场景预设 | 基地台→手台 / 手台→基地台 | 必选 |
| 频段 | 144 / 430 MHz | 144 MHz |
| 具体频率 | MHz，两位小数 | 144 默认 145.00；430 默认 435.00 |
| 发射功率 | W 或 dBm | 两单位联动换算 |
| 发射天线增益 | dBi 或 dBd | 默认 dBi；dBd 自动加 2.15 转为 dBi |
| 发射天线高度 | m AGL | 预设填入，可编辑 |
| 发射点地面海拔 | m AMSL | 默认 DEM 自动；可切换为手动覆盖 |
| 接收天线增益 | dBi 或 dBd | 默认 dBi，可编辑 |
| 接收天线高度 | m AGL | 预设填入，可编辑 |
| 极化 | 水平 / 垂直 | 默认垂直 |

接收点海拔不作为全局输入；每个 1 km 像素从 DEM 自动取得。

### 5.2 输入范围

- 功率：0.1–1000 W，或等价 dBm。
- 天线增益：-20–30 dBi。
- 天线结构高度：0.5–500 m。
- 手动发射点海拔：-500–9000 m。
- 数值为空、非数字或超出范围时禁止计算并就地提示。
- 功率范围用于模拟，不构成合法发射功率建议。

发射点地面海拔覆盖遵循以下固定语义：

- 请求字段为可空的 `txGroundElevationOverrideM`；字段缺失或 `null` 都表示 DEM 自动，有限数值表示手动覆盖，并兼容未携带该字段的旧请求。
- 即使选择手动覆盖，软件仍必须读取并校验中心 DEM；缺失、NoData 或损坏仍阻断计算，手动值不能绕过数据完整性检查。
- 手动值只替换每条 ITM PFL 的第一个发射端地形样点。发射天线高度始终是独立的 AGL 值，其余剖面高程、接收点高程和全部 WBM 采样仍来自数据集。
- 切换场景预设保留当前 DEM/手动模式及手动值；地图选择新发射点时重置为 DEM 自动。

### 5.3 新手预设

基地台 → 手台：

- 发射功率 25 W。
- 发射增益 6 dBi。
- 发射高度 20 m AGL。
- 接收增益 -3 dBi。
- 接收高度 1.5 m AGL。

手台 → 基地台：

- 发射功率 5 W。
- 发射增益 -3 dBi。
- 发射高度 1.5 m AGL。
- 接收增益 6 dBi。
- 接收高度 20 m AGL。

预设只是自动填表，所有数值都可以修改。

## 6. 结果与热力图

每个像素的结果是预测接收功率：

`P_rx_dBm = P_tx_dBm + G_tx_dBi + G_rx_dBi - L_ITM_dB`

首版馈线损耗固定为 0 dB，不在界面显示。

使用固定连续色标，保证不同计算之间可比较：

| dBm | 颜色 |
|---|---|
| ≥ -60 | 红 |
| -60 至 -75 | 橙 |
| -75 至 -90 | 黄 |
| -90 至 -105 | 绿 |
| -105 至 -120 | 青 |
| -120 至 -140 | 蓝 |
| < -140 | 完全透明 |

颜色只表示预测 dBm，不表示“保证通联”。热力图是不可检查的整体结果层，不响应像素悬停、单击或单点 dBm 查询。

计算进行中可以显示渐进式热力图，但它只是本次任务的临时预览：

- 尚未完成的像素保持透明；已经完成的像素仍使用与最终结果相同的固定 dBm 色标。
- 预览不能导出、不能写入历史或结果缓存，也不显示为一份已完成结果。
- 新计算、取消、失败、选点、参数变化或“清空热力图”都立即使旧预览失效。
- 计算成功后，最终权威结果必须原子替换预览；100% 完成状态只属于最终结果。
- 性能很快的计算可以直接显示最终结果，不要求至少出现一帧预览。
- 像素并行完成顺序不构成产品语义；预览可以块状或不均匀填充，不能据此判断传播方向或计算优先级。

## 7. 地图与离线数据

- 发射点只能通过地图单击设置。
- 地图范围允许平移和缩放，但发射点必须在中国大陆有效范围内。
- 海岸或边境站点仍计算完整 200 km 圆形，因此数据覆盖需包含大陆边界外至少 200 km 缓冲。
- 软件自带低体积基础地图；高程与水体数据按区域下载。
- 公开发行版只能使用来源合法、边界表示合规、具有有效审图信息并获得桌面/离线使用授权的底图。
- 底图不显示山体阴影、等高线、坡度、地形三维效果或任何高程视觉层。
- 所有持久数据合计硬上限为十进制 2.5 GB，即 2,500,000,000 字节，用户不能提高或降低。
- 达到上限后停止新下载并引导用户删除缓存；不静默删除已缓存区域。
- 缓存页显示类型、大小和已缓存区域，支持删除选中区域、清计算缓存和清全部数据。
- “清空热力图”不删除任何已下载数据。
- 未缓存区域在离线状态下不得用零海拔或伪造数据继续计算。

## 8. 清空与替换规则

- 地图始终只有一个发射点。
- 选择新点时清除旧热力图、移动发射点，并把发射点地面海拔来源重置为 DEM 自动。
- 新计算直接替换旧结果。
- “清空热力图”只删除当前热力图，保留发射点、参数表单、地面海拔模式/手动值和缓存状态，允许同一点立即重新计算。
- 不保存历史结果。

## 9. 导出

合规底图、审图号和导出授权就绪前，只允许导出带不可移除“内部测试，不得公开发布”标识的诊断报告。该报告不含行政边界或未授权底图，不得作为公开版地图。以下完整地图要求仍是正式发行门槛。

内部诊断报告和正式地图导出均不得依赖当前窗口裁剪；参数、结果和生成时间在导出开始时冻结，所有文件只写入用户在 Windows 原生保存对话框中选择的位置。

导出中的发射点地面海拔数值及“DEM 自动/手动覆盖”来源必须读取已完成计算的冻结结果，不能在计算后从仍可变化的表单或重新检查的 DEM 推断。

### PNG

- 导出完整 200 km 圆形区域，不依赖当前屏幕裁剪。
- 包含发射点、比例尺、固定色标、频率和关键参数。
- 默认文件名包含日期、频率和发射点坐标。

### PDF

- 单页横向报告。
- 包含地图、图例、发射点坐标、输入参数、计算时间、模型名称和版本、数据来源和版本。
- 包含“不考虑建筑、植被、外部干扰、实时天气和异常传播”的限制说明。
- 写入坐标前不另做隐私确认，因为全部操作均在本机；隐私说明中明确导出文件含坐标。

## 10. 非功能需求

- 支持 Windows 10/11 64 位。
- 支持浅色和深色主题，首次启动跟随系统，用户选择持久保存。
- 普通四核 CPU 上目标 60 秒内完成一次已缓存区域计算；这是性能目标，需通过原型基准确认。
- UI 在计算和下载期间不得冻结。
- 计算可以取消；取消后不保留半成品作为可导出结果。
- 相同模型版本、数据版本和输入必须产生相同结果。
- 软件无遥测，坐标、参数和结果不上传。
- 错误日志只保存在本机，可从设置页打开日志目录。
- 界面首版简体中文，但文本资源从第一天支持国际化。
- 提供 NSIS 64 位安装版和便携 ZIP；首版不自动安装更新。

## 11. 验收标准

1. 单击有效点后能够下载或读取地形，完成 200 km 圆形 dBm 热力图。
2. 平坦地形上，距离增加时信号总体减弱。
3. 单一山脊后形成明显附加衰减区。
4. 提高发射天线后，部分遮挡区改善。
5. 发射功率增加 10 倍时，同一像素 dBm 增加约 10 dB。
6. 相同条件下 144 与 430 MHz 结果存在合理差异。
7. 水平与垂直极化可以切换并进入 ITM 输入。
8. 陆地与水面路径使用不同电气参数并产生可测差异。
9. 同输入重复计算结果一致。
10. 200 km 外没有热力图像素，低于 -140 dBm 的像素透明。
11. 无缓存、无网络时禁止计算并给出可行动提示。
12. 任何情况下持久数据总量不会超过 2,500,000,000 字节。
13. PNG 和 PDF 可在另一台 Windows 电脑正常打开。
14. 底图不出现山体阴影、等高线或高程着色，热力图不提供像素检查交互。
15. 浅色和深色主题下，六色色标含义、阈值和导出结果保持一致。
16. DEM 自动与手动发射点地面海拔均能计算；手动模式仍校验中心 DEM，并只改变发射端 PFL 首样点而不改变 AGL、其余 DEM 或 WBM 语义。
17. 计算结果冻结有效发射点地面海拔及 `dem/manual` 来源；新点重置 DEM 自动，清空热力图保留当前点和覆盖设置。
18. 长计算可逐步显示透明未完成区域的临时覆盖层；预览不可导出，取消/失败/输入变化后不残留，成功时由最终双 PNG 结果替换。

## 12. 发布前合规门槛

- 确认项目及所有依赖许可证兼容 Apache-2.0。
- 保留 Copernicus DEM 要求的来源声明。
- 不使用 `tile.openstreetmap.org` 实现离线预取；官方策略明确禁止该用途。
- 中国大陆公开发行前，必须确认底图来源、国界表示、审图号、服务授权和公开地图审核要求。地图合规属于 P0 发布阻断条件。
- 不自行绘制、修订、裁切或重新解释国界和省级行政边界；不把国际开源边界数据直接放入公开发行版。
- 需要在应用地图界面和导出文件中按要求保留底图来源与审图号。
- 在发布页明确本软件不是应急通信可靠性保证或法规合规判断工具。

## 13. 已确认的产品默认值

- 英文名 `HamHeatmap`，中文名“业余无线电传播热力图”，内部包名 `hamheatmap`。
- 默认频率为 145.00 MHz 和 435.00 MHz。
- 浅色/深色双主题，默认跟随系统。
- 热力图不可检查单个像素。
- 所有持久数据共享不可修改的 2.5 GB 硬上限。
- 首次启动显示三页简短引导和预测限制说明，可从帮助页重新打开。
- 参数变化时旧热力图降低透明度并标记“结果已过期”，重新计算前禁止导出。
- 普通安装版可在缺少 WebView2 时联网补装；便携离线版包含所需运行组件。
- Apache-2.0 许可；MVP 可运行后再建立公开 GitHub 仓库。
