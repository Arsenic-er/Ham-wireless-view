# ADR 0022：视觉底图仅在线，传播数据继续支持离线计算

- 状态：已接受；代码与自动化已完成，受管运行尚待切换
- 日期：2026-08-02
- 范围：Windows/Tauri、私有 validation、地图缓存边界
- 取代：ADR-0017 的当前 PMTiles 主路径、ADR-0018 的离线地图/本地 places 回退，以及 ADR-0021 对未来离线地图包的预留
- 保留：ADR-0020 的 Windows 天地图安全代理，以及 ADR-0017/0018/0021 已发生的历史验证证据

## 背景

项目所有者决定取消离线视觉底图及后续离线地图包，普通地图、卫星图和地名均改为在线获取。该决定不改变传播模型对真实高程和水体数据的要求，也不把卫星或在线地图像素用于传播计算。

截至本决策记录时，私有 validation 运行服务尚未按本 ADR 重启，服务器运行目录仍保留约 33 MB 的四省 PMTiles 历史验证资产，天地图 token 也尚未配置。因此本文只改变现行产品与架构目标，不把未部署、未删除或未实测的状态写成完成。

## 决策

### 1. 在线视觉底图

1. Windows/Tauri 普通地图固定使用天地图 `vec+cva`，卫星图固定使用 `img+cia`，继续由用户提供个人 `tk`。
2. Windows 原生 `tianditu:` 协议、当前用户 DPAPI、固定主机/路径/图层白名单、零重定向、有界响应、图片签名校验和 `no-store` 保持不变。
3. 私有 validation 普通地图使用现有同源天地图 `vec/cva` 代理；卫星图继续使用固定同源 EOxCloudless Sentinel-2 2025 代理。
4. 在线中文地名来自各在线地图的注记层。当前产品不再依赖 PMTiles `places`、本地地名字体数据或离线地名文件。
5. 在线瓦片不得写入 Rust 数据根、SQLite、浏览器持久存储、Service Worker、诊断导出或任何离线包。

### 2. 失败降级

1. 缺少 Key/token、断网、上游失败、配额耗尽或瓦片校验失败时，不切换到 PMTiles 或其他未知地图源。
2. 地图回退为 WGS84 内部坐标网格，并保留 camera、当前发射点、历史站点、200 km 圆、比例尺和已有/新计算热力图。
3. 界面必须区分凭据已保存、连接自检成功和当前底图不可用，不得伪造在线地图成功状态。
4. EOxCloudless 卫星失败时可以先回退在线天地图普通地图；若普通地图也不可用，则回退 WGS84 坐标网格。

### 3. DEM/WBM 与离线计算保持

1. GLO-90 DEM/WBM 仍按用户选择区域下载、校验、原子提交并持久缓存；地形遮挡、绕射、海拔和陆水参数继续只使用这些计算资产。
2. 十进制 2,500,000,000 字节硬上限继续覆盖 DEM、WBM、partial、SQLite/索引、计算缓存和其他持久运行数据，但不为视觉底图预留或计费。
3. 已缓存完整 DEM/WBM 的区域在无网络时仍可运行 ITM、显示热力图并导出不含底图的诊断 PNG/PDF。
4. 未缓存或损坏的 DEM/WBM 继续阻断计算，绝不以零高程、在线地图像素或卫星影像替代。
5. “取消离线地图”只取消视觉底图资产，不取消计算数据缓存、缓存管理、区域删除、断点续传或离线传播计算。

### 4. 历史资产与证据

1. 四省 PMTiles 不再是当前产品能力。相关 Range、哈希、图层白名单、地名与浏览器测试记录保留为历史工程证据，不能改写为从未发生。
2. ADR-0017 与 ADR-0018 标记为被本 ADR 取代；ADR-0021 仅离线地图包边界被取代，其场强阈值决策继续有效。
3. 当前约 33 MB PMTiles 运行资产的删除是独立的受管清理任务；完成前文档必须明确“尚未删除”，不能只因目标改变就声称磁盘已释放。
4. PMTiles JavaScript、fflate 和 Protomaps 归档在代码/构建完全移除前继续保留许可证记录；移除后转入历史验证清单，不作为当前发行物料。

## 后果

- 产品联网时提供普通地图、卫星图和在线中文注记；无网时只有 WGS84 网格与传播分析层。
- 视觉地图可用性不再决定已缓存区域是否能计算，但会影响用户对道路、行政地名和卫星地表的视觉参照。
- 不再实现离线地图包下载、导入、manifest、哈希安装、地图缓存删除或地图配额预算。
- 代码切换、依赖清理与自动化测试已完成；仍需完成受管 validation 重启、真实 token/tk 和 Windows 10/11 实机验证。
- 天地图与 EOxCloudless 的可用性、许可、署名、服务额度和中国大陆真实网络仍是在线产品门槛。
