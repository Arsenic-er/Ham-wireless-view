# ADR-0024：双点链路通视、菲涅尔净空与规划结果分类

- 状态：Accepted
- 日期：2026-08-02
- 范围：产品状态、WGS84 路径剖面、NTIA ITM 点对点调用、链路预算、SVG 结果
- 关联：ADR 0004、0006、0014、0023

## 背景

现有 MVP 只允许用户设置一个发射点并计算固定 200 km 圆形覆盖。项目所有者要求新增双点链路通视分析：地图依次选择发射站和接收站，分别配置两端天线高度、增益和极化，显示路径地形剖面、长距离地球曲率、第一菲涅尔区与距离刻度，并给出三类容易理解的规划结果。

菲涅尔区本身不是“能通信/不能通信”的硬边界。地形侵入第一菲涅尔区会增加衍射损耗，严重遮挡仍可能存在绕射或对流层散射；反之，即使几何视距良好，功率、增益、极化或接收门限也可能使链路预算不足。因此三类结果必须联合几何、ITM 和链路余量，且不得写成现场保证。

现有 ITM PFL 使用原始地形剖面，模型内部已处理有效地球曲率和标准折射。若先把地球隆起写回 DEM 再送入 ITM，或在 ITM 损耗之外追加刀刃绕射损耗，会重复计算。

## 决策

1. 顶层提供独立的 coverage 与 link 模式。两者分别持有选点、参数、任务、错误和结果；切换模式、切换语言、主题或地图样式不丢失状态。清空链路不清热力图，清空热力图也不清链路。
2. 链路模式第一次地图单击选择 TX，第二次选择 RX，并显示不同标记和 WGS84 测地线。首版仅接受 1 km <= D <= 200 km；越界保留 TX、拒绝计算并允许重选 RX。
3. 路径按 WGS84 测地线等距离采样，间隔不超过 90 m，包含精确首尾点。单条 200 km 路径最多约 2,224 个样本，逐样本使用精确 WGS84 正算，不沿用覆盖批量计算的球面内部点性能近似。
4. DEM 使用与覆盖相同的 GLO-90 双线性高程采样，WBM 使用相同的分类像素规则。缺瓦片、NoData、损坏、版本混用或只有 DEM/WBM 单边缺失均 fail closed；只有现有“同单元 DEM/WBM 成对 404”规则可以生成确定性纯海洋资产。
5. 原始 DEM 高程直接构造一次 ITM Point-to-Point PFL。ITM 继续使用 land-water-v1、50/50/50、N_0 = 301、气候 5 和沿路径水体比例；不把剖面显示用地球曲率写回 PFL，不在 ITM 基本损耗之外叠加 P.526 刀刃绕射损耗。
6. 几何通视与 SVG 剖面固定使用标准规划值 k = 4/3 和平均地球半径 Re = 6,371,008.8 m。对总距离 D 和距 TX 距离 x：

       effective_radius = k * Re
       bulge(x) = 2 * effective_radius
                  * sin(x / (2 * effective_radius))
                  * sin((D - x) / (2 * effective_radius))
       display_terrain(x) = terrain_amsl(x) + bulge(x)
       ray(x) = lerp(tx_antenna_amsl, rx_antenna_amsl, x / D)
       F1(x) = sqrt(lambda * x * (D - x) / D)
       clearance(x) = ray(x) - display_terrain(x)
       normalized_clearance(x) = clearance(x) / F1(x)

   归一化净空只在内部样本计算，端点的 F1 = 0 不参与最小值。`bulge` 使用当前源码的精确正弦式；`x * (D - x) / (2 * k * Re)` 只作为短路径近似和回归对照。显示层采用抬高地形与直线射线的等价表示，但原始 DEM 与地球隆起分别保留，ITM PFL 只使用原始 DEM。
7. SVG 绘制曲率抬高后的显示地形、端点直线射线、完整 +/-1.0 F1 半透明包络、0.6 F1 净空边界、TX/RX 和最严重净空点；游标仍读取完整样本中的原始 DEM 与地球隆起。Y 轴为 m AMSL 并提示纵向比例可能放大；X 轴覆盖 0..D，按可视宽度选择 5–9 的目标密度并用 1/2/5 * 10^n 步长生成动态公制距离刻度。不开放热力图像素检查。
8. 频率沿用 144–148 MHz 与 430–440 MHz、两位小数和 145.00/435.00 MHz 默认值。两端分别输入 0.5–500 m AGL 天线高度、-20–30 dBi 或等价 dBd 增益与水平/垂直极化；TX 另有 0.1–1000 W 或等价 dBm 功率。RX 规划接收门限可编辑，默认 -120 dBm，不代表具体设备。
9. 馈线、接头、人体、建筑物和方向图损耗保持 0 或不建模。两端同极化的失配损耗为 0 dB；水平/垂直正交时使用版本化 cross-polar-v1 = 20 dB 规划假设，并在参数摘要和结果中明确显示。实际失配随天线、姿态、反射和环境变化。
10. 链路预算为：

        rx_dbm = tx_dbm + tx_gain_dbi + rx_gain_dbi
                  - itm_basic_loss_db - polarization_mismatch_loss_db
        margin_db = rx_dbm - receiver_threshold_dbm

11. 三类结果的稳定代码和条件如下：

    - direct-los：无线电射线无地形遮挡、最小归一化净空 >= 0.60、ITM 模式为视距且 margin_db >= 0。
    - obstructed-usable：不满足全部 direct-los 条件，但 margin_db >= 0。详情分别显示射线是否受挡、F1 净空和 ITM 的视距/绕射/对流层散射模式。
    - predicted-unavailable：margin_db < 0，并显示预算不足、地形遮挡和极化失配等诊断因素。

    ITM 未知模式、非有限损耗或不完整剖面是错误，不能强行归类。margin_db = 0 属于预计可用；60% 净空边界包含等号。
12. 用户文案使用“视距良好（菲涅尔净空充分）”“遮挡传播（模型预测仍可用）”“当前参数下预计不可用”。所有结果都明确是当前 DEM、标准大气、模型默认值、输入和门限下的规划预测，不使用“保证能通信”或“完全无法通信”。
13. 新 UI、状态、SVG 标签、错误和限制说明必须同时加入 en、zh-CN、zh-TW、ja-JP，保持 key parity；语言切换不重建地图或 SVG 数据模型。

## 备选方案

- 只按地形是否穿过直线分三类：拒绝；不会使用功率、增益、极化和接收门限，也无法判断预测链路是否高于门限。
- 把“地形位于第一菲涅尔区内”直接当成可通信：拒绝；菲涅尔净空不是解调门限。
- 在 ITM 结果上追加单刀刃绕射损耗：拒绝；会重复计算。
- 把曲率修正后的剖面送入 ITM：拒绝；ITM 已包含有效地球曲率。
- 使用理想正交极化并得到无限损耗：拒绝；真实传播会去极化，MVP 使用明确可见的规划假设。
- 与覆盖模式共用单一选点/清空状态：拒绝；会重现选新点导致旧结果消失或清空误删的状态问题。

## 后果

- 旧需求中“两点链路分析不在 MVP”和“不提供接收灵敏度/能否解调判定”的排除项被替换：链路模式进入第一版，并加入用户可见的规划接收门限；仍不提供调制、带宽、设备库或保证解调结论。
- 链路分析可以复用现有 DEM/WBM、ITM、单位换算、缓存完整性和国际化基础，但需要新的独立请求/结果 schema、状态机、地图 TX/RX 图层和 SVG 组件。
- 90 m DEM 可能漏掉建筑物、植被和窄山脊；一维中心线剖面也不是完整三维菲涅尔椭球碰撞检查。结果页必须保留该限制。
- k = 4/3 是标准大气规划值，不反映实时折射；水面反射、多径和异常传播仍不单独建模。
- 默认 -120 dBm 和正交极化 20 dB 都是显式、版本化的规划假设，后续修改必须新建版本并重跑分类、预算和 UI 回归。
