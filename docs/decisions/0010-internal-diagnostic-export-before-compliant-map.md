# ADR 0010：合规底图前只提供内部诊断报告导出

- 日期：2026-07-16
- 状态：已采纳；2026-08-02 起正式 provider 的离线授权字段由 ADR-0022 改为在线显示/叠加授权，内部诊断导出决策不变

## 背景

MVP 要求导出 PNG 和单页 PDF，但中国大陆公开发行的底图来源、审图号、离线权和导出权尚未确定。直接截取开发画布或加入 OSM、Natural Earth 等国际边界会把内部工程功能误当成可公开发布的地图导出。

同时，Windows 开发机只能保留最终 EXE；导出必须离线、单机完成，不能引入云服务或要求用户安装 PDF 工具。

## 决策

- 当前阶段只导出固定 1600×1100 的内部诊断报告画布，不截取当前窗口，也不包含行政边界或未授权底图。
- 报告强制显示“内部测试，不得公开发布”，并包含 200 km 圆、100 km 比例尺、发射点、固定 dBm 色标、输入、统计、ITM/数据版本、生成时区和模型限制。
- 浅色/深色界面都生成相同的规范化浅色报告，避免主题改变传播颜色。
- PNG 保存报告画布；PDF 把同一 PNG 无损嵌入 A4 横向单页，避免中文字体分发和跨电脑字体替换。
- 前端只生成报告 Data URL。独立 `hamheatmap-export` Rust crate 校验 MIME、Base64、1600×1100 IHDR、完整解码和负载上限，生成 PDF，并使用同目录临时文件后原子替换。
- Tauri Rust 命令内部打开 Windows 原生保存对话框；WebView 不获得宽泛文件系统权限。
- 参数、结果和生成时间在导出开始时冻结；导出属于全局 busy operation，期间禁止重复导出和修改结果。

## 公开发行硬门槛

内部诊断导出不关闭正式地图合规门槛。接入正式在线底图后，只有供应者清单同时具备有效审图号、署名、热力图叠加授权和所需导出授权，生产模式才允许输出带底图的地图。任一字段缺失必须拒绝正式地图导出，不能只隐藏水印。

## 结果

优点：

- 当前可以验证完整 PNG/PDF、Windows 保存路径和离线流程。
- PNG/PDF 中文外观一致，不依赖目标电脑额外字体。
- 不引入不合规边界，不扩大 WebView 文件权限。
- 编码与写入逻辑可在 Linux/Windows 目标独立测试。

限制：

- 当前产物是诊断报告，不是正式合规地图。
- 热力图仍使用当前 401×401 局部等距栅格；最终 Web Mercator 重投影误差门槛尚未关闭。
- Windows 原生保存、覆盖长路径和另一台电脑打开仍需实机验收。
