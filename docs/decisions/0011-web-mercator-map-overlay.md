# ADR 0011：为 MapLibre 生成轴对齐 Web Mercator 地图覆盖层

- 日期：2026-07-24
- 状态：已采纳

## 背景

传播计算的规范结果是以发射点为中心的局部等距网格：`401×401` 个样本中心、相邻样本 1 km、有效半径 200 km。原始 PNG 直接对应这张栅格，适合计算诊断和内部报告。

此前地图把原始 PNG 的四个 WGS-84 对角点交给 MapLibre `image` source。MapLibre 会先把四角转为 Web Mercator，再以两个三角形做分片仿射插值；该变换不能表达“局部等距坐标 → WGS-84 测地位置 → EPSG:3857”的非线性关系。对四角直接映射的复核得到最大平面定位误差：纬度 18° 为 2.035 km、30.5° 为 3.685 km、40° 为 5.244 km、54° 为 8.587 km，均超过 1 km 输出容差。即使改用理想的四角双线性插值，也不能在中国大陆纬度范围内稳定满足 1 km 门槛。

因此不能通过调整四角顺序、增加一个中心点或仅修改 MapLibre 参数关闭风险，必须在进入地图渲染前把结果重采样到地图实际使用的投影。

## 决策

- 保留传播引擎输出的原始 `401×401` dBm 栅格和原始 `401×401` PNG。内部诊断报告继续使用原始 PNG，不因地图投影改变计算证据。
- 另行生成一个 `401×401` 地图覆盖层，投影标识固定为 `EPSG:3857`。它与报告 PNG 是同一计算结果的两种渲染产品，不重复执行 ITM。
- 覆盖层边界是包含原始样本域的轴对齐 Web Mercator 矩形。边界在首末输出像素中心之外各扩展半个输出像素，使 MapLibre 图像外边缘语义与栅格像素中心语义一致，避免 0.5 像素偏移和边界裁切。
- 对每个目标像素中心执行反向重采样：EPSG:3857 反算 WGS-84，经发射点到目标点的测地反算取得距离和方位，再换算到局部等距网格坐标，最后从原始 dBm 栅格做 NaN 感知双线性采样。
- 双线性邻域只对有限 dBm 值归一化权重；没有有限贡献时输出透明。距发射点超过 200 km、落在原始域外、原始 NoData 或色标阈值以下的目标像素均保持透明。
- MapLibre 只接收该 EPSG:3857 覆盖层和轴对齐四角；不再把原始局部等距 PNG 的四个 WGS-84 角点直接交给 `image` source。
- 桌面服务契约同时返回报告 PNG 和地图覆盖层 PNG，并显式携带覆盖层投影、宽高和四角。前端只渲染地图覆盖层，报告渲染器继续使用原始 PNG。
- 相同输入必须生成字节确定的覆盖层 PNG；重采样不能改变传播模型版本、原始 dBm 栅格或报告统计。

## 验收门槛

- 原始 PNG 与地图覆盖层都固定为 `401×401`。
- 地图覆盖层四角在 EPSG:3857 中构成轴对齐矩形，MapLibre 两三角插值不再引入额外非线性形变。
- 纬度 18°、30.5°、40°、54° 的代表性中心均需证明地图像素定位误差小于 1 km。
- 中心和四个 199 km 内侧方向 alpha 可见；精确 200 km 连续边界点位于半像素扩展图像域内。由于 1 km 像素中心离散化，精确边界最近中心可透明，但 `3×3` 邻域内必须存在不超过该处一个 WGS-84 实算输出像素对角线的可见中心。
- 圆外、原始 NaN 和无有效双线性邻域保持透明；有限邻域的权重重新归一化。
- 前端契约测试必须证明 MapView 使用地图覆盖层字段，而内部报告仍使用原始 PNG 字段。

## 结果

优点：

- 地图渲染坐标与 MapLibre 的 Web Mercator 插值方式一致，关闭四角两三角映射的公里级形变。
- 保留原始计算栅格，诊断报告、统计和传播回归不受地图显示方案影响。
- 输出尺寸仍为 `401×401`，不会把一次结果或 IPC 负载扩张为高分辨率地图瓦片。
- 半像素边界把像素中心、图像边缘和地图四角的语义固定下来，便于自动化回归。

代价与限制：

- 每次计算增加一次确定性的 CPU 重采样和第二张 PNG 编码；release 优化构建耗时仍需独立测量，Windows 10/11 WebView2 中的 MapLibre 实机几何仍需回归。
- Web Mercator 覆盖层是显示产品，不能回写或替代原始 dBm 栅格。
- 该决策只解决热力图叠加几何，不证明 ITM 预测精度，也不关闭中国大陆合规底图、审图号或正式地图导出门槛。

完整方法和验收记录见 `../13-web-mercator-overlay-validation.md`。
